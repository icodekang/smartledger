## 二、修复详情

### 2.1 问题列表

| 问题 | API 端点 | 错误类型 | 状态 |
|------|----------|----------|------|
| 票据列表错误 | GET /api/v1/invoices | 500 响应模型验证错误 | ✅ 已修复 |
| 银行流水错误 | GET /api/v1/bank-flows | 500 内部错误 | ✅ 已修复 |
| 审计待办错误 | GET /api/v1/audit/pending | 500 内部错误 | ✅ 已修复 |

### 2.2 问题根因

```python
# 问题代码示例
@router.get("", response_model=ResponseModel[BillListData])  # 期望 Pydantic 模型
async def list_invoices(...):
    ...
    return success_response(data={"items": [...], ...})  # 实际返回字典
```

- `success_response(data={...})` 返回普通字典
- `response_model=ResponseModel[BillListData]` 期望 `data` 字段为 `BillListData` Pydantic 模型实例
- FastAPI 响应验证时，字典无法通过 Pydantic 模型验证，导致 500 错误

### 2.3 修复方案

移除所有端点的 `response_model` 参数，与 `vouchers.py` 的实现保持一致：

```python
# 修复后代码
@router.get("")  # 移除 response_model
async def list_invoices(...):
    ...
    return success_response(data={"items": [...], ...})  # 正常返回字典
```

### 2.4 修改文件
