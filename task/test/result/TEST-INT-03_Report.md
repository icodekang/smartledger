### 5.1 借贷平衡算法验证

**测试案例**: 一般纳税人采购专票，金额1000元，税额130元

**预期分录**:
```
借：原材料          1000.00
借：应交税费-进项税  130.00
贷：应付账款        1130.00
```

**验证结果**:
- ✅ 借方总额 = 1000 + 130 = 1130
- ✅ 贷方总额 = 1130
- ✅ 借贷平衡
