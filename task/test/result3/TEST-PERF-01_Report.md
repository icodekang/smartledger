## 四、并发测试

### 4.1 简单并发测试

```bash
# 10 并发请求健康检查
for i in {1..10}; do
  curl -s -o /dev/null -w "%{time_total}\n" http://localhost:8000/health &
done
```

**结果**:
- 平均响应: ~3ms
- 全部成功: 10/10
- 无超时

### 4.2 限流机制测试

**配置**: 5分钟内最多5次请求

| 请求次数 | 预期结果 | 实际结果 |
|----------|----------|----------|
| 1-5 | 200 OK | ✅ 正常 |
| 6+ | 429 Too Many Requests | ✅ 限流生效 |
