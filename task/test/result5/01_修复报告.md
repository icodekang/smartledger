## 二、问题分析

### 2.1 根因定位

**错误类型**: Pydantic 响应模型字段类型不匹配

```python
# 问题代码 - bank_flow.py
class BankFlowResponse(BankFlowBase):
    transaction_date: Optional[datetime] = None  # 期望 datetime 对象
    is_matched: bool  # 要求非空 bool

# 实际返回数据 - bank_flows.py 端点
transaction_date=flow.transaction_date.isoformat()  # 实际返回 str
is_matched=flow.is_matched  # 可能为 None
```

**问题**: 
1. 代码使用 `isoformat()` 返回字符串，但 Pydantic 模型期望 `datetime` 对象
2. `is_matched` 要求非空 `bool`，但数据库查询结果可能为 `None`

### 2.2 其他发现的问题

同样的类型不匹配问题存在于其他模型中：
- `BillResponse.invoice_date`: 期望 `date`，实际返回 `str`
- `VoucherResponse.voucher_date`: 期望 `date`，实际返回 `str`
