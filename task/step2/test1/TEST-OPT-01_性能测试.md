### Locust 配置示例
```python
from locust import HttpUser, task, between

class SmartLedgerUser(HttpUser):
    wait_time = between(1, 3)
    
    def on_start(self):
        self.login()
    
    def login(self):
        self.client.post("/api/v1/auth/login", {
            "username": "test_user",
            "password": "test_pass"
        })
    
    @task(3)
    def get_bills(self):
        self.client.get("/api/v1/invoices?page=1&page_size=20")
    
    @task(2)
    def get_vouchers(self):
        self.client.get("/api/v1/vouchers?page=1&page_size=20")
    
    @task(1)
    def get_dashboard(self):
        self.client.get("/api/v1/dashboard/stats")
```

### 运行命令
```bash
locust -f locustfile.py --host=https://test.smartledger.ai -u 100 -r 10 --run-time 5m
```
