# 测试任务：TEST-BANK-03
# 任务名称：票据流水匹配测试
# 优先级：P0
# 预估工期：1.5天
# 测试类型：功能测试/算法测试

================================================================================
                          一、测试目标
================================================================================

验证票据与银行流水的自动匹配算法准确性，以及匹配界面的人工干预功能。

================================================================================
                          二、测试数据准备
================================================================================

### 匹配测试数据集

| 票据 | 金额 | 日期 | 销售方 | 期望匹配流水 |
|------|------|------|--------|--------------|
| 发票001 | 11300.00 | 2024-03-01 | XX科技有限公司 | 流水A (支出11300) |
| 发票002 | 5600.00 | 2024-03-02 | YY贸易公司 | 流水B (支出5600) |
| 发票003 | 10000.00 | 2024-03-03 | ZZ电子商行 | 无匹配 |

### 流水测试数据
- 流水A：2024-03-01，支出 11300.00，对方：XX科技有限公司
- 流水B：2024-03-02，支出 5600.00，对方：YY贸易
- 流水C：2024-03-03，支出 10000.00，对方：AA公司（名称不匹配）

                          三、测试用例

## 3.1 自动匹配算法测试

### TC-BANK-03-001 完美匹配（金额+日期+名称）
**测试数据**：发票001 vs 流水A
**预期结果**：
- 匹配分数 = 1.0（或 ≥0.95）
- 标记为 auto_match = true
- 匹配原因：金额一致、日期一致、名称一致
**验收**：✅ / ❌

### TC-BANK-03-002 金额日期匹配，名称模糊匹配
**测试数据**：发票002 vs 流水B（"YY贸易公司" vs "YY贸易"）
**预期结果**：
- 匹配分数 ≥ 0.75
- 名称相似度 ≥ 80%
**验收**：✅ / ❌

### TC-BANK-03-003 仅金额匹配
**测试数据**：发票003 vs 流水C
**预期结果**：
- 匹配分数 ≈ 0.5（仅金额权重）
- 日期不匹配扣分
- 名称不匹配扣分
**验收**：✅ / ❌

### TC-BANK-03-004 金额不一致
**测试数据**：发票001（11300）vs 错误流水（11350）
**预期结果**：
- 匹配分数 < 0.6
- 不被标记为自动匹配
**验收**：✅ / ❌

### TC-BANK-03-005 日期相差1天
**测试数据**：票据 2024-03-01 vs 流水 2024-03-02
**预期结果**：
- 日期匹配得分 ≈ 0.9（±3天容忍）
- 总分数略低于完美匹配
**验收**：✅ / ❌

### TC-BANK-03-006 日期相差5天
**测试数据**：票据 2024-03-01 vs 流水 2024-03-06
**预期结果**：
- 日期匹配得分 = 0（超出±3天范围）
**验收**：✅ / ❌

### TC-BANK-03-007 多候选匹配
**测试数据**：一张票据对应多条相似流水
**预期结果**：
- 返回多个候选，按分数排序
- 只标记最高分的为 auto_match
**验收**：✅ / ❌

### TC-BANK-03-008 无匹配
**测试数据**：无对应流水的票据
**预期结果**：
- 返回空列表或低分列表（< 0.5）
- 不自动匹配
**验收**：✅ / ❌

## 3.4 确认匹配接口测试

### TC-BANK-03-015 确认自动匹配

- 数据库 match_status 更新为 matched
- matched_bill_id 正确设置
**验收**：✅ / ❌

### TC-BANK-03-016 人工选择其他候选
