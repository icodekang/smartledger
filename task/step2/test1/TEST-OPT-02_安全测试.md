## 3.1 认证安全测试

### TC-OPT-02-001 密码复杂度校验
**测试数据**：
- "123456" → 应拒绝
- "password" → 应拒绝
- "Password1" → 应通过
- "MyP@ssw0rd" → 应通过
**预期结果**：弱密码被拒绝注册
**验收**：✅ / ❌

### TC-OPT-02-002 密码历史检查
**测试步骤**：
1. 修改密码为 password1
2. 再次修改为 password1
**预期结果**：提示"不能与最近使用过的密码相同"
**验收**：✅ / ❌

### TC-OPT-02-003 登录失败锁定
**测试步骤**：
连续 5 次输入错误密码
**预期结果**：
- 账户锁定 30 分钟
- 提示"登录尝试次数过多"
**验收**：✅ / ❌

### TC-OPT-02-004 Token 吊销
**测试步骤**：
1. 登录获取 Token
2. 用户登出
3. 使用原 Token 访问接口
**预期结果**：返回 401，Token 已失效
**验收**：✅ / ❌

### TC-OPT-02-005 Token 过期
**测试步骤**：
使用过期 Token 访问
**预期结果**：返回 401，提示重新登录
**验收**：✅ / ❌
