## 1. 认证安全测试

### TEST-SYS-SEC-001 密码复杂度校验
**测试步骤**:
1. 注册时输入弱密码: `123456`
2. 输入中等密码: `Password1`
3. 输入强密码: `P@ssw0rd!2024`
**预期结果**:
- 弱密码: 拒绝，提示"密码至少8位，需包含大小写字母、数字、特殊字符"
- 中等密码: 可能通过或提示增强
- 强密码: 通过

### TEST-SYS-SEC-002 密码历史校验
**测试步骤**:
1. 用户修改密码为近期使用过的密码
**预期结果**:
- 提示"不能重复使用最近 5 次密码"
- 拒绝修改

### TEST-SYS-SEC-003 登录失败锁定
**测试步骤**:
1. 使用错误密码连续登录 5 次
2. 第 6 次尝试登录
**预期结果**:
- 提示"账户已锁定，请 30 分钟后重试"
- 锁定期间即使正确密码也无法登录

### TEST-SYS-SEC-004 登录失败计数重置
**测试步骤**:
1. 失败 3 次后成功登录
**预期结果**:
- 失败计数清零
- 再次失败从 1 开始计数

### TEST-SYS-SEC-005 Token 过期处理
**测试步骤**:
1. 登录后等待 Token 过期
2. 执行需要认证的操作
**预期结果**:
- 返回 401 Unauthorized
- 提示"登录已过期"
- 跳转登录页

### TEST-SYS-SEC-006 Token 吊销
**测试步骤**:
1. 用户 A 登录获取 Token
2. 用户 A 执行登出
3. 使用原 Token 访问接口
**预期结果**:
- Token 失效
- 拒绝访问

## 2. SQL 注入测试

### TEST-SYS-SEC-010 常规 SQL 注入
**测试数据**:
- `' OR '1'='1`
- `'; DROP TABLE users; --`
- `1' UNION SELECT * FROM users --`
**测试位置**: 所有用户输入接口
**预期结果**:
- 所有注入被过滤或转义
- 数据库无异常操作

### TEST-SYS-SEC-011 盲注测试
**测试数据**:
- `1 AND 1=1`
- `1 AND 1=2`
- `1 AND SLEEP(5)`
**预期结果**:
- 响应时间无差异
- 无法通过时间差异获取信息

---

## 3. XSS 测试

### TEST-SYS-SEC-020 反射型 XSS
**测试数据**:
- `<script>alert('xss')</script>`
- `<img src=x onerror=alert('xss')>`
- `javascript:alert('xss')`
**测试位置**: 搜索框、URL 参数
**预期结果**:
- 脚本不执行
- 内容被转义或过滤

### TEST-SYS-SEC-021 存储型 XSS
**测试步骤**:
1. 在票据备注中输入 XSS payload
2. 保存后其他用户查看
**预期结果**:
- 显示为纯文本，无脚本执行
- 数据库中存储转义后的内容

### TEST-SYS-SEC-022 DOM 型 XSS
**测试位置**: 前端 URL hash、location
**预期结果**:
- 无 DOM 操作导致的 XSS
- innerHTML 使用安全

**测试步骤**:

### TEST-SYS-SEC-031 跨域请求测试
**测试步骤**:
1. 从其他域名发送 AJAX 请求
**预期结果**:
- 被 CORS 策略拒绝
- 无敏感数据泄露

## 5. 权限控制测试

### TEST-SYS-SEC-040 水平越权
**测试步骤**:
1. 用户 A 登录
2. 尝试访问用户 B 的票据数据
**预期结果**:
- 返回 403 Forbidden
- 或返回"无权限访问"

### TEST-SYS-SEC-041 垂直越权
**测试步骤**:
1. 普通会计登录
2. 尝试访问管理员接口
**预期结果**:
- 拒绝访问
- 接口权限控制生效

### TEST-SYS-SEC-042 未登录访问
**测试步骤**:
1. 清除登录状态
2. 访问需要登录的页面
**预期结果**:
- 重定向到登录页
- 或返回 401

## 6. 文件上传安全测试

### TEST-SYS-SEC-050 上传可执行文件
**测试数据**:
- `shell.php`
- `script.js`
- `malware.exe`
**预期结果**:
- 拒绝上传
- 或上传后无法执行

### TEST-SYS-SEC-051 文件类型伪装
**测试数据**:
- 将 PHP 文件重命名为 `.jpg`
**预期结果**:
- MIME 类型检测阻止
- magic number 检测阻止

**测试数据**: 20MB 文件
**预期结果**:
- 上传被阻止
- 返回大小限制提示

### TEST-SYS-SEC-053 路径遍历
**测试数据**: `../../../etc/passwd`
**测试位置**: 文件名、下载路径
**预期结果**:
- 文件名被清理
- 无法访问系统文件

## 7. 敏感数据保护测试

### TEST-SYS-SEC-060 传输加密
**测试步骤**:
1. 抓包分析登录请求
2. 查看数据传输
**预期结果**:
- 使用 HTTPS
- 密码不明文传输

### TEST-SYS-SEC-061 敏感字段存储
**测试位置**: 数据库
**预期结果**:
- 密码使用 bcrypt 加密
- 银行账号使用 AES 加密
- 日志中无敏感信息

### TEST-SYS-SEC-062 响应数据脱敏
**测试步骤**:
1. 普通用户获取票据详情
2. 查看响应数据
**预期结果**:
- 完整税号脱敏显示（如：123456****7890）
- 银行账号脱敏

### TEST-SYS-SEC-080 会话固定攻击
**测试步骤**:
1. 攻击者获取会话 ID
2. 用户登录后会话 ID 应变化
**预期结果**:
- 登录后会话 ID 更新
- 防止会话固定

**测试步骤**:
1. 同一账号在多地同时登录
**预期结果**:

- 或踢出之前登录
