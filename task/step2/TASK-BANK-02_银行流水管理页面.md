## 1. 银行流水列表页 (/bank-flows)

### 1.1 页面布局
```
┌─────────────────────────────────────────────────────────────────┐
│  银行流水管理                              [导入流水]            │
├─────────────────────────────────────────────────────────────────┤
│  筛选区: 日期范围 | 匹配状态 | 关键词 | [查询] [重置]            │
├─────────────────────────────────────────────────────────────────┤
│  统计卡片: 总收入 | 总支出 | 未匹配 | 余额趋势                   │
├─────────────────────────────────────────────────────────────────┤
│  表格:                                                           │
│  □ | 日期 | 收入 | 支出 | 对方户名 | 摘要 | 匹配状态 | 操作     │
├─────────────────────────────────────────────────────────────────┤
│  分页                                                            │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2 功能需求

**表格列定义**:
| 列名 | 说明 | 特殊处理 |
|------|------|----------|
| 选择框 | 批量操作 | - |
| 交易日期 | 格式: 03-01 | 按日期排序 |
| 收入 | 金额，收入为正 | 绿色文字 |
| 支出 | 金额，支出为负 | 红色文字 |
| 对方户名 | 交易对手 | 过长省略 |
| 摘要 | 交易说明 | 过长省略 |
| 匹配状态 | unmatched/matched/ignored | 标签显示 |
| 操作 | 查看详情、删除 | - |

**筛选条件**:
- 日期范围选择器（快捷选项：本月、上月、本季度、本年）
- 匹配状态：全部/未匹配/已匹配/已忽略
- 关键词搜索（对方户名、摘要）
- 金额范围（最小~最大）

**统计卡片**:
- 总收入（本月）
- 总支出（本月）
- 未匹配笔数
- 账户余额趋势（迷你图表）

### 1.3 交互细节

**批量操作**:
- 选中多行后显示批量操作栏
- 支持：批量删除、批量标记已匹配

**行内操作**:
- 点击行展开详情（原始数据 JSON）
- 点击"匹配票据"打开匹配对话框

### 2.2 组件设计

**文件上传组件**:
```vue
<BankFlowUpload
  v-model:visible="showUploadDialog"
  @success="handleUploadSuccess"
/>
```

Props:
- `visible`: 控制显示
- `customerId`: 当前客户ID

Events:
- `success`: 导入成功，返回导入统计
- `error`: 导入失败

## 3. API 对接

```typescript
// api/bank-flow.ts
export const bankFlowApi = {
  // 上传并解析
  upload: (file: File, bankType: string) => 
    axios.post('/bank-flows/upload', formData),
  
  // 确认导入
  import: (data: ImportData) => 
    axios.post('/bank-flows/import', data),
  
  // 获取列表
  getList: (params: ListParams) => 
    axios.get('/bank-flows', { params }),
  
  // 删除
  delete: (id: string) => 
    axios.delete(`/bank-flows/${id}`),
  
  // 批量删除
  batchDelete: (ids: string[]) => 
    axios.post('/bank-flows/batch-delete', { ids }),
  
  // 获取统计
  getStatistics: (params: StatParams) => 
    axios.get('/bank-flows/statistics', { params })
}
```

## 4. 数据结构

```typescript
// types/bank-flow.ts
interface BankFlow {
  id: string
  transaction_date: string
  transaction_time?: string
  amount: number  // 正=收入, 负=支出
  balance?: number
  counterparty_name?: string
  counterparty_account?: string
  summary?: string
  transaction_type?: string
  match_status: 'unmatched' | 'matched' | 'ignored'
  matched_bill_id?: string
  matched_bill?: Bill
  created_at: string
}

interface BankFlowListResponse {
  items: BankFlow[]
  total: number
  summary: {
    total_income: number
    total_expense: number
    unmatched_count: number
  }
}

interface UploadPreviewResponse {
  preview: BankFlowPreviewItem[]
  total_count: number
  date_range: { start: string; end: string }
  amount_summary: { income: number; expense: number }
  errors?: { row: number; message: string }[]
}
```
