## 🎯 关键技术决策

### 多租户方案
- **方案A：独立数据库**（推荐）
  - 每个客户独立 PostgreSQL Schema
  - 数据完全隔离，安全性高
  - 便于独立备份恢复

### 报表生成
- **后端**：Python + pandas / openpyxl
- **前端**：ECharts 图表展示
- **导出**：PDF (ReportLab) + Excel (openpyxl)

### 定时任务
- **框架**：Celery + Redis
- **调度**：celery-beat
- **监控**：Flower

### 消息通知
- **邮件**：SendGrid / AWS SES
- **短信**：阿里云短信
- **站内信**：WebSocket 实时推送
