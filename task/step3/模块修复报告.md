# 模块修复报告

## 修复时间
2026-03-08

## 问题描述
以下模块API返回404错误：
- ❌ 合同管理、账套管理、统计分析
- ❌ 角色权限、操作日志、系统参数
- ❌ 财务报表
- ❌ 多租户、消息通知

## 根本原因
1. **system.py** 使用 `sys_router` 而非标准 `router`
2. **advanced.py** 使用 `adv_router` 而非标准 `router`
3. **router.py** 未导入和注册 system 和 advanced 模块
4. **permissions.py** 缺少相关权限定义

## 修复内容

### 1. system.py
```python
# 修复前
sys_router = APIRouter(prefix="/sys", tags=["系统管理"])
@sys_router.get("/users")

# 修复后
router = APIRouter(prefix="/sys", tags=["系统管理"])
@router.get("/users")
```

### 2. advanced.py
```python
# 修复前
adv_router = APIRouter(prefix="/adv", tags=["高级功能"])
@adv_router.get("/tenant/config")

# 修复后
router = APIRouter(prefix="/adv", tags=["高级功能"])
@router.get("/tenant/config")
```

### 3. router.py
```python
from app.api.endpoints import (
    ..., system, advanced  # 新增
)

router.include_router(system.router)   # 新增
router.include_router(advanced.router) # 新增
```

### 4. permissions.py
添加权限：
- `sys:users:read`, `sys:roles:read`, `sys:logs:read`, `sys:config:read`
- `adv:tenant:read`, `adv:backup:read`, `adv:scheduler:read`, `adv:notifications:read`

## 修复后的API列表

### 系统管理 (/api/v1/sys)
- GET    /sys/users          - 用户列表
- POST   /sys/users          - 创建用户
- PUT    /sys/users/{id}     - 更新用户
- DELETE /sys/users/{id}     - 删除用户
- GET    /sys/roles          - 角色列表
- GET    /sys/logs           - 操作日志
- GET    /sys/config         - 系统配置
- PUT    /sys/config         - 更新配置

### 高级功能 (/api/v1/adv)
- GET    /adv/tenant/config              - 租户配置
- POST   /adv/backup                     - 创建备份
- GET    /adv/backup/tasks               - 备份任务
- GET    /adv/scheduler/jobs             - 定时任务
- POST   /adv/scheduler/jobs/{id}/toggle - 切换任务状态
- GET    /adv/notifications              - 消息通知列表
- POST   /adv/notifications              - 创建通知
- POST   /adv/notifications/{id}/read    - 标记已读
- GET    /adv/notifications/unread-count - 未读数量
